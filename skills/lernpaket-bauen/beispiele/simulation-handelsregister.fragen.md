# LZ1 · Register nutzen

## C1 · LZ1 · mc · check

Welche Stelle führt das Handelsregister?

- [x] Das Amtsgericht (Registergericht)
- [ ] Das Landgericht → Das Landgericht ist für größere Streitfälle zuständig, das HR führt das Amtsgericht.
- [ ] Die Industrie- und Handelskammer → Die IHK berät und prüft Anmeldungen mit, führt das Register aber nicht. Das macht das Amtsgericht.

> Das Handelsregister wird beim zuständigen Amtsgericht geführt.

## C2 · LZ1 · mc · check

Wozu dient das Handelsregister?

- [x] Jeder kann sicher prüfen, mit wem er Geschäfte macht.
- [ ] Es zeigt, wie viel Gewinn ein Unternehmen macht. → Geschäftszahlen stehen nicht im HR. Es geht um die rechtlichen Verhältnisse. Siehe Kapitel 1.
- [ ] Das Finanzamt berechnet damit die Steuern. → Das HR dient der Rechtssicherheit im Geschäftsverkehr, nicht der Steuerberechnung. Siehe Kapitel 1.

> Das HR liefert einen zuverlässigen Nachweis der rechtlichen Verhältnisse von Kaufleuten und schafft so Rechtssicherheit.

## C3 · LZ1 · mc · check

Wie muss eine Firma eine Änderung zum Handelsregister anmelden?

- [x] Elektronisch, in öffentlich beglaubigter Form
- [ ] Formlos per E-Mail an das Gericht → Das Gericht muss sich auf die Echtheit verlassen können, deshalb ist die Form vorgeschrieben.
- [ ] Notariell beurkundet auf Papier → Beurkundung ist nicht nötig, öffentliche Beglaubigung und elektronische Einreichung genügen.

> Anmeldungen und Änderungen werden elektronisch in öffentlich beglaubigter Form eingereicht.

## C12 · LZ3 · mc · check
